User: why does this happen on Chrome? [screenshot: WorkloadControls value labels "6" / "30 min" clipped past the card's right edge]

Agent: Classic flexbox + native range-input overflow, Chrome-specific. Each slider row is `[label w-28][input flex-1][value w-14]`; flex items default to `min-width:auto` so they won't shrink below intrinsic min size, and Chrome/WebKit give `<input type=range>` a built-in intrinsic min width (Firefox lets it collapse, so it doesn't repro there). In the 20rem right column there wasn't enough room for that minimum, so the input refused to shrink, the row overflowed the card, and the value span got pushed off the right edge + clipped. Fix: added `min-w-0` to the range input so it can shrink to fill remaining space (label/value keep their `shrink-0` fixed widths). Build clean. CSS-only.
